# Supplementary Materials: Rover Locomotion on Granular Terrain

**Energy Efficiency of Rover Locomotion on Granular Terrain: A Comparative Modeling Study**

Oliver Cheng, Yolanda Fan, and Yixuan Liang

This repository is intended to support review and reproduction of the paper's computational analysis. The supplementary package includes the MATLAB model, published-source data and provenance, numerical results, figures, and an independent numerical verification script.

The study uses published secondary data and conditional models of rolling, inching, and screw propulsion. Energy estimates depend on the stated power and resistance assumptions; the results do not establish measured Mars rover performance.

## Availability

The supplementary code and data files have not yet been uploaded. This repository is not yet ready for reviewer use.
